# 01 — Getting Started

Welcome to your development lab. This guide sets up your mindset and environment.

## What is software development?

Building software means telling a computer **what to do** using code, then running that code so users (including you) get something useful — a website, an API, a mobile app, or a SaaS product.

A typical web app stack looks like this:

```
Browser (HTML/JS/React)
        ↓ HTTP requests
Backend (Python API)
        ↓ queries
Database (PostgreSQL / MongoDB)
```

You'll touch every layer in this repo.

## First commands to try

Open a terminal in this folder and run:

```bash
git status
```

You should see whether files are tracked, modified, or untracked. We'll use this constantly.

Check Python:

```bash
python --version
```

You want 3.11 or newer.
