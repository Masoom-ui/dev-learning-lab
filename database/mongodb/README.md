# MongoDB

Start the database:

```bash
docker compose up -d mongodb
```

Connection string:

```
mongodb://devlab:devlab@localhost:27017
```

Use [MongoDB Compass](https://www.mongodb.com/products/compass) to browse data visually, or we'll query from Python in a later lesson.

See [docs/07-mongodb.md](../../docs/07-mongodb.md) for the learning guide.
